## Turn on the overlay

Applies to the installed app; the browser demo mode doesn't open the local server.

1. Open **Chat → Set up → Overlays**.
2. Turn on **Overlays for OBS**.
3. Under **Alerts** or **Chat**, click **Add to OBS**.
4. In OBS, confirm the new **Browser Source** in the current scene.
5. Position and resize the source.
6. Go back to Corneta and use the test button.

## Adjust before the stream

For alerts, set position, scale, duration, sound and followers. For chat, adjust font size, maximum messages, badges, platform icon, commands and the time before messages fade out.

The URL uses loopback and the configured local port. Don't swap it for a public IP or open the port on your router.

## If it doesn't show up

| Symptom                     | How to confirm               | Fix                                             |
| --------------------------- | ---------------------------- | ----------------------------------------------- |
| source doesn't exist in OBS | look in the current scene    | click **Add to OBS** again                      |
| empty frame                 | send a test from Corneta     | refresh the Browser Source cache                |
| URL doesn't open            | check that the overlay is on | turn it off and on again, and check the port    |
| no sound                    | test audio monitoring in OBS | turn on sound and the source's audio properties |

If it still fails, write down the port and the message. Don't share your alert sources' tokens.
