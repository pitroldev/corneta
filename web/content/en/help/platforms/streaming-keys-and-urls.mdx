## The difference in one table

| Field              | What it is                                      | Where you get it                                  | Where you paste it                     |
| ------------------ | ----------------------------------------------- | ------------------------------------------------- | -------------------------------------- |
| Ingest URL         | Address of the server that receives the stream  | The platform's dashboard or documentation         | In the Corneta destination             |
| Stream key         | Password that points the stream to your channel | Twitch, YouTube, Kick or other platform dashboard | In the Corneta destination             |
| Local OBS key      | Identifier of the link between OBS and Corneta  | Live screen → Hook up OBS                         | OBS → Settings → Stream                |
| WebSocket password | Password that lets Corneta control OBS          | OBS → Tools → WebSocket Server Settings           | Corneta's first-time setup or Settings |

## Ingest URL

It starts with `rtmp://` or `rtmps://`. It's a streaming address, not a page
that opens in your browser. Twitch, YouTube, Facebook and Kick already come with
the default server in Corneta. For TikTok, X, Instagram and **Custom RTMP**, you
paste the full address the platform shows you.

## Stream key

It works as your channel's password. Anyone who has this key can try to stream
to your account. If it showed up in a screenshot or in chat, revoke it in the
platform's dashboard and generate a new one — deleting the message doesn't undo
the leak.

<ContentImage baseName="corneta-platform-key-setup-en" />

If you paste a full URL into the key field, Corneta tries to split off the
address and store only the key. Even so, check both fields. The **Test the
server** button only checks whether the address answers; it doesn't check the
key. The key only proves it's right when the stream goes live.

## The local key shown in Hook up OBS

This key only works on your computer. It makes OBS publish to Corneta's local
server, usually at the address `127.0.0.1`. Then Corneta opens a separate output
for each platform.

<ContentImage baseName="corneta-obs-connection-details-en" />

## The WebSocket password

The WebSocket doesn't carry the video. It lets Corneta check, configure, start
and stop OBS. If you set everything up by hand, the stream works without this
password, but Corneta won't control OBS for you.

<Callout label="What never to send to support" tone="important">
  Don't send a stream key, WebSocket password, token, URL with credentials or a
  screenshot where one of those fields is visible. The error message and the
  name of the step are enough to start the diagnosis.
</Callout>

Now that the fields are sorted out, [add and test the
platform](/en/help/platforms/manage-platform).
