## First test

In OBS 28 or later, open **Tools → WebSocket Server Settings**. WebSocket comes built in; don't install a separate plugin unless you need to.

1. Turn on the WebSocket server.
2. Check that **Server Port** is set to `4455`. Corneta doesn't let you change this port.
3. Keep **Enable Authentication** on.
4. Click **Show Connect Info**, copy the password and paste it into **Settings → OBS** in Corneta.
5. Click **Test connection** or go back to **Hook up OBS**.

## By symptom

| Message in Corneta                           | Likely cause                                                                                                     | Fix                                                                                 |
| -------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| Couldn't find OBS                            | OBS is closed, the WebSocket is off or the port isn't 4455. Up to 0.8.5, a wrong password also shows up this way | open OBS, turn on the server, set the port back to 4455 and copy the password again |
| Password refused                             | OBS asks for a password and Corneta has none or, after 0.8.5, a different one                                    | paste the password into **Settings → OBS**                                          |
| Connected, but OBS isn't pointing at Corneta | OBS is streaming to another server                                                                               | click **Set it up for me** on the **Live** screen                                   |
| Connected, but **Waiting for signal**        | the WebSocket is fine; the video hasn't arrived                                                                  | start streaming in OBS                                                              |

If OBS froze, close it and open it again. Antivirus software with its own firewall can also block the connection: allow OBS and Corneta in it.

Don't turn off the password just to “see if it works” on a shared network. The OBS documentation recommends protecting the WebSocket.

If it keeps happening, write down the message and the versions. Never send the WebSocket password.
