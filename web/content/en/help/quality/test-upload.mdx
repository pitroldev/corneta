## Before you measure

Applies to Corneta 0.6.0 on Windows 11. Connect your PC the way it will be during the stream, close backup uploads and let other people on the network use it as usual. A test on an empty network can promise headroom that disappears at night.

## Run the test

1. Open **Quality**.
2. Choose **Straight up**, **Smart** or **All out**.
3. Click **measure now**.
4. Wait for the value to show up in **Your internet uploads at**.
5. Compare it with the upload shown for each mode.

<ContentImage baseName="corneta-upload-test-result-en" />

The expected state is **fits your upload with room to spare**. If the margin is tight, lower the bitrate, use fewer re-encodes or test over a cable.

## If the result doesn't match the stream

| Symptom                            | Likely cause                 | How to confirm                    | Fix                                  |
| ---------------------------------- | ---------------------------- | --------------------------------- | ------------------------------------ |
| high test, stream loses connection | routing or brief fluctuation | check dropped frames in OBS       | cable, another ingest, lower bitrate |
| result varies a lot                | Wi-Fi or a contested network | repeat at different times         | stabilize the connection             |
| only one platform drops            | that destination's route     | compare states on the Live screen | test another ingest                  |
| test doesn't finish                | firewall or no internet      | try another connection            | allow Corneta through and repeat     |

If it keeps happening, note the time, the mode and the measured value. Don't share your key, IP, PC name or raw logs.
